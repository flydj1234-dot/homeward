위치 소식은 어떻게 오나요?

API 키나 결제 없이 Open Waters AIS에 연결합니다. 페이지를 열면 마지막 수신 위치를 조회하고 새 위치 신호를 구독합니다.

  1. 수신 시각이 기준입니다
    30분이 지난 기록은 ‘오래된 AIS 기록’으로 표시합니다. 연결되어 있어도 선박의 새 위치가 수신된 것은 아닙니다.
  2. 대양에서는 기록이 오래될 수 있어요
    무료 수신망에 이 배의 신호가 들어와야 갱신됩니다. 위성 기반 연속 추적이나 최신 위치를 보장하지 않습니다.
  3. 화면을 열어 두면 자동 갱신
    새 신호가 오면 지도와 수신 시각이 바뀝니다. 화면을 닫으면 구독은 멈추며, 다시 열 때 마지막 위치를 조회합니다. 수동 기록은 새 AIS 수신 시 교체됩니다.

이 지도는 선박 위치를 보여주며, 동생의 개인 위치나 안전 상태를 확인하는 서비스는 아닙니다. 이 사이트는 링크를 가진 누구나 열 수 있습니다. 직접 기록한 위치는 각자의 브라우저에만 저장됩니다.
